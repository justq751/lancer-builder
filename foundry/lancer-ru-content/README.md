# LANCER — русский перевод контента

Модуль для Foundry VTT 13 и LANCER 3.1.3. Использует перевод из `locales/ru` проекта lancer-builder. Переводит названия и описания шасси, оружия, систем, модификаций, талантов, навыков, бонусов ядра, снаряжения пилота, состояний и тегов. Core и восемь официальных дополнений сопоставляются по `system.lid` и типу документа.

## Установка

1. Распакуйте `lancer-ru-content.zip` в каталог `Data/modules`, чтобы файл оказался по пути `Data/modules/lancer-ru-content/module.json`.
2. Перезапустите сервер Foundry, если модуль добавлен впервые.
3. В тестовом мире LANCER включите **Babele** (2.9.1 или новее), **lib-wrapper**, **Russian Translation (ru-ru)**, **LANCER — дополнительный русский перевод интерфейса** и этот модуль. Установите русский язык.
4. Импортируйте нужные книги штатным LCP Manager. После создания новых справочников перезагрузите страницу.
5. Откройте справочники мира: мехи/оружие/системы (`world.mech-items`), пилотские предметы (`world.pilot-items`), состояния (`world.status-items`). Перетащите предмет на лист.

Для нового мира сначала импортируется обычный английский контент, затем модуль показывает перевод. Повторно импортировать книги только ради перевода не требуется. Модуль не содержит собственных compendium-баз и не заменяет LCP Manager.

## Границы перевода

- `ru-ru` и `lancer-ru-ui-patch` отвечают за основной интерфейс. Этот модуль дополнительно исправляет заголовки характеристик и статичные подписи листа шасси, которые система 3.1.3 не локализует корректно.
- Уже сохранённые предметы мира и предметы внутри персонажей автоматически не обновляются. Для них не выполняется массовая миграция.
- Копия, перетащенная из переведённого справочника, может сохранить русский текст. Отключение модуля не переводит такие копии обратно. Исходные базы справочников модуль не переписывает.
- Текст применяется только при совпадении с известным английским исходником. При сравнении учитываются эквивалентные `<br>`, `<br/>`, `<br />` и регистр слова REPAIRS в данных 3.1.3. Другие изменения текста не игнорируются. Изменённые тексты и неизвестный homebrew остаются как есть. Некоторые поля обновлённых LCP могут остаться английскими; числовые поля и ссылки не заменяются.
- Сайт складывает часть действий и развёртываемого снаряжения в описание родителя. В модуле это описание переведено целиком; отдельные вложенные действия и Actor развёртываемого снаряжения могут оставаться английскими, если для них нет отдельного перевода.
- Для Thermal Charge `on_hit` не имеет отдельного целевого поля в unpacker модификаций 3.1.3; перевод основного эффекта сохраняется. Подробности адаптации и исключений — `coverage.json`.
- NPC, bonds, reserves, журналы, произвольный текст биографии пилота и категории вне словаря сайта не переводятся.
- Теги переводятся в клиентском объекте Tag, а не в настройке мира; числовые значения и сериализация `lid/val` сохраняются.

## Обновление из репозитория

Из корня lancer-builder:

```text
npm run foundry:build
npm run test:foundry
```

На Windows при запрете PowerShell-скриптов используйте `npm.cmd`. Нужен Python 3.10+ и Node 24. Сборка не добавляет зависимостей. Архив создаётся в `foundry/releases/lancer-ru-content.zip`; готовые JSON и `generated/runtime-data.js` вручную не редактируются.

`tools/export_foundry_locale.py --check` проверяет воспроизводимость экспорта. Английские варианты берутся из сохранённых upstream-снимков, русский текст — из существующих локалей; `coverage.json` перечисляет адаптации схемы и пропуски. При обновлении системы или книг требуется повторная проверка в тестовом мире.
