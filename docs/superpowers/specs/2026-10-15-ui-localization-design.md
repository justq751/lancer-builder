# Локализация интерфейса (Этап 4 `PLAN.md`) — дизайн

> 2026-10-15 · Согласовано по частям в обсуждении · Следующий шаг — план
> реализации (`superpowers:writing-plans`).

## Цель

Все тексты интерфейса уходят из кода в файлы переводов, интерфейс можно
показать целиком по-английски, новый язык добавляется файлом без правки кода.

**Готово, когда:** при интерфейсе и данных `en` на экране нет кириллицы, и это
проверяет тест; русский интерфейс выглядит как сейчас (скриншоты не меняются).

**Не цель:** перевод данных (этап 5), третий язык, перевод имён собственных.

## Решения

### 1. Два независимых языка

| Настройка | Ключ `localStorage` | Что переключает |
|---|---|---|
| Язык интерфейса | `lancer_ui_lang` (новый) | кнопки, заголовки, подсказки, диалоги, сокращения, `<html lang>` |
| Язык данных | `lancer_lang` (существующий, смысл не меняется) | тексты из `data/` + `locales/`, а также `tr()`/`trTag()` |

Режим «русский интерфейс + английские данные» — это сверка с оригиналом
(`PRODUCT.md`, принцип 5), он сохраняется.

**Первый заход** (`detectLanguages(navigatorLang, stored)` — чистая функция):

| Сохранено | `navigator.language` | Интерфейс | Данные |
|---|---|---|---|
| оба ключа | — | сохранённый | сохранённый |
| только `lancer_lang` (пользователь до этапа 4) | — | `ru` (как было) | сохранённый |
| ничего | `ru…` | `ru` | `ru` |
| ничего | другой | `en` | `en` |

### 2. Файлы строк

- **`data/ui.json`** — канонический английский. Плоский объект
  `{"ключ": "текст"}`; строка с числом — объект форм
  `{"one": "{n} skill", "other": "{n} skills"}`.
- **`locales/ru/ui.json`** — `{"ключ": {"en": "…", "ru": "…"}}`, формы
  множественного числа — `{"en": {...}, "ru": {"one","few","many"}}`.
  Генерирует и обновляет `tools/extract_locale_template.py`.
- Пустой `"ru"` → английская строка (принцип «частичный перевод = рабочий
  сайт»).

### 3. Загрузка и `t()`

- `loadUiStrings(uiLang)` в `js/i18n-loader.js`: для `en` — только
  `data/ui.json`; для `ru` — оба файла, русский поверх английского.
  Результат — глобальный `UI` (рядом с `L`, `M`). Загружается отдельно от
  данных, потому что языки независимы.
- **`t(key, params)`** — в `js/core/i18n.js` (без DOM, тестируется в Node):
  - строка по ключу из `UI`; нет ключа → возвращает ключ и один раз
    `console.warn`;
  - `{name}` подставляется из `params`, значение экранируется; HTML самой
    строки (`<b>`) не трогается — файл наш;
  - если значение — объект форм, форма выбирается
    `new Intl.PluralRules(uiLang).select(params.n)`.
- Статическая разметка `index.html` (кнопки шапки, `<title>`, загрузочный
  экран, скрытый `<h1>`, ссылка «К содержимому») получает
  `data-i18n="ключ"` (и `data-i18n-attr="aria-label:ключ"` для атрибутов);
  `applyStaticStrings()` проходит по ним.
- Смена языка интерфейса: `loadUiStrings()` → `applyStaticStrings()` →
  `document.documentElement.lang = uiLang` → `render()`. Сборка не меняется.

### 4. Переключатели

- Кнопка `#t-lang` показывает **состояние**: `RU`, `EN` или `RU · EN`
  (интерфейс · данные, если различаются); `aria-label` — полная фраза
  («Язык: интерфейс русский, данные английские»). Место прежнее: шапка на
  десктопе, меню «⋯» на телефоне.
- По нажатию — popover-панель (на телефоне шторка снизу):

  ```
  // ЯЗЫК
  ИНТЕРФЕЙС     [ RU · Русский ] [ EN · English ]
  ДАННЫЕ ИГРЫ   [ RU · Русский ] [ EN · English ]
  Английские данные — оригинал Massif Press, для сверки с книгой правил.
  ```

  Каждая строка — `fieldset` + `legend` с настоящими `radio`, оформленными
  сегментами. Названия языков — на самом языке. Применяется сразу. Пока
  грузятся данные, строка «Данные» показывает «…» и заблокирована.
  Закрывается Esc и щелчком мимо.
- Лист и печать: подписи на языке интерфейса, содержимое на языке данных.
  Ссылка `?s=` язык не несёт.

### 5. Правила переноса строк

Объём — ~440 строк с кириллицей в 25 файлах (комментарии не в счёт).
Английский текст пишется в терминах официального COMP/CON (*License Level*,
*Mech Skills*, *Core Bonus*, *Pilot Gear*, *Loadout*).

**Ключи** — по месту:

| Группа | Содержимое |
|---|---|
| `common.*` | повторяющиеся слова: close, back, install, remove, selected, none |
| `topbar.*`, `boot.*`, `lang.*`, `a11y.*` | шапка, загрузочный экран, панель языка, `<h1>` и «К содержимому» |
| `hud.*`, `ledger.*`, `tabs.*` | HUD, строка бюджета, названия вкладок |
| `pilot.*`, `skills.*`, `talents.*`, `hase.*`, `licenses.*`, `frame.*`, `loadout.*`, `core.*`, `summary.*` | по вкладке |
| `picker.*`, `sheet.*`, `print.*` | окна выбора, лист, печать |
| `dialog.*`, `error.*`, `save.*`, `dropped.*` | диалоги, ошибки, статус сохранения, «что отброшено» |
| `term.*` | сокращения: КИНЕТ, ДИСТ, УКЛ… |

**Правила:**

1. Значки (⬇ ⟲ 🔒 ▶) остаются в разметке, в строке — только текст.
2. Подстановки по имени (`"Потрачено {used} из {cap}"`), без склейки кусков.
3. Множественное число — формы в `ui.json`; помощник
   `n(count, one, few, many)` в `js/app/state.js` удаляется.
4. **Игровой термин**, у которого есть словарь в данных (`stat_labels`,
   `enums`, `glossary`), берётся оттуда — по языку данных. Всё остальное,
   включая сокращения, — `ui.json`, по языку интерфейса.
5. Сообщения `js/core/` («отброшен навык «…»») — через `t()`; `core`
   остаётся без DOM, юнит-тесты кладут `UI` в контекст.
6. `console.*` — обычный английский, без `t()` (это текст для разработчика).
7. Время автосохранения — `Intl.DateTimeFormat(uiLang, {hour, minute})`.
8. Без `t()`: «LANCER», «COMP/CON», имена Massif Press, коды производителей
   (GMS, IPS-N…). Слово бренда переводится: «РЕЕСТР» / «REGISTRY».

**Порядок:** инфраструктура (`t()`, загрузка, переключатели) → перенос файл за
файлом с прогоном тестов после каждого. Golden `L` и русские скриншоты должны
оставаться неизменными — любое изменение означает потерянную или искажённую
строку.

### 6. Инструменты и формат данных

`tools/extract_locale_template.py`:

- обработчик **`ui`**: `data/ui.json` → `locales/ru/ui.json`. Если английский
  текст строки изменился, а перевод был — перевод сохраняется с пометкой
  `"stale": true` (на сайте показывается он; `t()` пометку не читает).
  Вывод: «ui.json: N переводов устарело, ищите "stale"»;
- обработчик **`mods`**: `locales/ru/mods.json` в общий формат — у `name`,
  `effect`, `description` появляется `"en"` рядом с прежним `"ru"`. Русские
  тексты не меняются; проверка — golden `L` не сдвинулся;
- `enums.json`, `stat_labels.json`, `glossary.json` (ручные) не трогаются.

### 7. Документы

- **`GLOSSARY.md`** (корень) — EN → RU: термин, перевод, где встречается,
  примечание. Источник — существующие переводы, новых терминов не
  придумывается. Разделы: структура меха, статы, крепления и типы оружия,
  урон и дальность, теги, пилот, лицензии, интерфейс. Раздел «Открытые
  вопросы» — найденные разночтения (например, «Чёрная Борода» /
  «Блэкберд», AUDIT P2-5) — решает владелец проекта; исправления в данных —
  этап 5.
- **ADR в `docs/adr/`** (по-русски, контекст → решение → последствия):
  0001 ключи логики переводятся только при показе · 0002 без шага сборки ·
  0003 `reserves`/`environments` не поддерживаются · 0004 формат локалей
  данных · 0005 локализация интерфейса (разделы 1–5 этого документа).
- **`CLAUDE.md`, `README.md`** — раздел «Тексты интерфейса»: новый текст на
  экране — только ключ в `data/ui.json`, кириллицы в коде нет.

## Тестирование

**Юнит (`tests/unit/`):**

- `t()`: поиск; нет ключа → ключ + одно предупреждение; экранирование
  параметров при сохранении HTML строки; плюралы `ru` (1, 2, 5, 21) и `en`
  (1, 2).
- наложение `ru` поверх `en`, пустой `"ru"` → английский.
- `detectLanguages()`: все четыре строки таблицы из раздела 1.
- сверка ключей: каждый `t("…")` / `data-i18n` в `js/` и `index.html` есть
  в `data/ui.json`, неиспользуемых ключей нет.
- полнота: в `locales/ru/ui.json` все ключи, русский заполнен, набор
  `{подстановок}` совпадает с английским.
- в `js/**/*.js` и `index.html` нет кириллицы вне комментариев.

**Браузер:**

- **EN без кириллицы**: интерфейс и данные `en`; все 9 вкладок, окна выбора
  (оружие, системы, моды, снаряжение пилота), окна деталей, диалог сброса,
  панель языка, лист, печатная версия — видимый текст и `title`,
  `aria-label`, `placeholder` без `[А-Яа-яЁё]`; сообщение указывает место.
- панель языка: смена интерфейса без перезагрузки меняет тексты и
  `<html lang>`, сборка цела; «RU · EN» — кнопки русские, описания
  английские; выбор переживает перезагрузку.
- первый заход: контекст `locale: "en-US"` → всё по-английски (конфиг
  тестов остаётся `ru-RU`, старые тесты идут по-русски без правок).
- регрессия: golden `L` не меняется; 21 русский скриншот не меняется;
  тесты с русскими текстами («✓ ВЫБРАНО», `getByLabel("Позывной")`) — без
  правок.
- новое: 2 английских скриншота (десктоп «Пилот», телефон «Вооружение»);
  «вкладки помещаются в 390 px» — и для `en`.

## Риски

- **Объём переноса** (~440 строк): ошибки ловят неизменные русские
  скриншоты, тест «EN без кириллицы» и статическая сверка ключей.
- **Длина английских строк** на узких экранах: английские скриншоты и тест
  ширины 390 px на `en`.
- **Двойная загрузка** при смене языка интерфейса — `data/ui.json` и
  `locales/ru/ui.json` маленькие, данные при этом не перезагружаются.
