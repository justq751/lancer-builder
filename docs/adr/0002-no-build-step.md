# Без шага сборки

Сайт — статические `index.html`, `css/`, `js/`, `data/`, `locales/`,
`assets/`, которые браузер исполняет как есть: обычные `<script src>` в
общей глобальной области, без бандлера, транспайлера и ES-модулей. npm —
только для тестов.

**Почему:** домашний проект с переводчиком, который правит JSON; любой
должен открыть файл в редакторе и увидеть то, что работает в браузере.
ES-модули рассматривались на этапе 3 и отклонены: пришлось бы переписать
обращения к общим изменяемым `L`, `M`, `state`, `activeTab` почти во всём
коде.

**Последствия:** порядок `<script>` в `index.html` значим — файл использует
имена из загруженных раньше; код верхнего уровня не вызывает функции из
файлов, загружаемых позже. Чистая логика живёт в `js/core/` (без DOM) и
тестируется в Node через `vm`.
