# Ключи логики переводятся только при показе

`frame.name` (и `frame.variant`) — ключ лицензий: `state.licenses[...]` и
сравнение `item.license === frame.name`; `mount`, `type`, `source`, `tags`,
`mechtype` сравниваются в коде буквально. Поэтому в данных они всегда
английские, а на экран попадают через `tr()` / `trTag()` по словарю
`locales/<lang>/enums.json`; русское имя шасси — отдельное поле
`display_name` (`dispName()`).

**Почему не переводить в данных:** перевод `frame.name` молча ломает
разблокировку оружия и систем, перевод `mount` — подбор креплений, а
сохранённые сборки и ссылки `?s=` хранят английские ключи.

**Последствие:** любое новое поле, которое участвует в сравнениях, тоже
остаётся английским в данных и переводится при показе.
