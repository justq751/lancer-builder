# Формат переводов данных: пары {en, ru} по id

Канонические английские данные лежат в `data/*.json`, перевод — в
`locales/ru/<категория>.json`: запись по `id` предмета, каждое поле — пара
`{"en": "…", "ru": "…"}`. Вложенные списки (`traits`, `ranks`, действия)
адресуются английским именем элемента, а не индексом. Перевод
накладывается на загрузке (`localizeData()`); пустой `"ru"` оставляет
английский текст.

**Почему так:**
- переводчик видит оригинал рядом с переводом;
- частичный перевод никогда не ломает сайт — непереведённое остаётся
  английским;
- ключ по имени, а не по индексу, переживает перестановку элементов при
  обновлении `lancer-data`.

**Последствие:** шаблоны генерирует `tools/extract_locale_template.py`.
Все категории, включая `mods.json` (приведён к общему формату на
этапе 4), имеют `"en"`.
